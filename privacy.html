Privacy Policy — Rotate PDF

Last updated: 19 August 2026

Rotate PDF ("the extension") is a Chrome extension that turns the pages of a PDF file you open and saves a corrected copy to your computer.

What we collect

Nothing. The extension has no backend, no account system, no analytics and no telemetry. We — the developer — never receive your documents, their contents, their file names or any identifier. There is no server to receive them: the extension makes no network requests at all, which you can verify in Chrome's DevTools Network tab.

What happens to your file

The file you open is read inside the browser tab, on your own computer:

  • the pages are rendered locally to show you the thumbnails;
  • the rotation you choose is written into a new copy of the file;
  • the copy is handed to Chrome's normal download flow, and the original file is never modified.

Nothing is uploaded anywhere, and nothing is kept after the tab is closed. The extension keeps no history of the documents you opened.

Permissions

The extension requests no permissions at all. It does not ask for storage, downloads, tabs or access to any website:

  • the file is chosen by you through the standard file picker or by dragging it into the page;
  • the result is saved through an ordinary download link.

Because there are no host permissions, the extension cannot read any website you visit.

Offline use

The extension works with no internet connection. Everything it needs — the PDF engine and the rendering code — ships inside the extension package.

Children

The extension is a document utility with no accounts, no content feed and no communication features. It collects nothing from anyone, including children under 13.

Changes
